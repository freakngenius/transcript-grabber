how it works

01yt-dlp

Sound only

For links, only the audio track comes down, about 1 MB a minute. Dropped files never leave this Mac.

02whisper.cpp

Transcribed here

Whisper large-v3-turbo runs on this Mac's GPU. Nothing goes to a transcription service.

03temp folder

Nothing kept

Temp copies are deleted when each job ends, and your original file is never changed. The text stays only if you save it.
